# PolicyEngine-UK Codex Routing

When working in `policyengine-uk`, prefer these PolicyEngine skills:

- `$policyengine-uk` for UK domain knowledge: entities, reform APIs, private data access.
- `$policyengine-model-development` for variables, parameters, periods, vectorization, YAML tests, and in-model reforms.
- `$review-program` for PR reviews.
- `$fix-pr` for applying review findings.
- `$policyengine-standards` for formatting, CI, and PR standards.

For generic prompts like `/review`, "add a parameter", "write tests", or "fix a failing test", load the relevant skills above before editing.
