# PolicyEngine-UK Codex Routing

When working in `policyengine-uk`, prefer these PolicyEngine skills:

- `$policyengine-uk` for household calculations and UK country-package APIs.
- `$policyengine-parameter-patterns` for parameter YAML files.
- `$policyengine-variable-patterns` for variable formulas and metadata.
- `$policyengine-testing-patterns` and `$policyengine-period-patterns` for YAML tests.
- `$policyengine-code-style`, `$policyengine-code-organization`, `$policyengine-aggregation`, and `$policyengine-vectorization` for implementation and review.
- `$policyengine-review-patterns` for reviewing UK model changes.

For generic prompts like `/review`, "add a parameter", "write tests", or "fix a failing test", load the relevant skills above before editing.
