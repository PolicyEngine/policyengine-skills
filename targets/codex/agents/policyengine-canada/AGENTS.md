# PolicyEngine-Canada Codex Routing

When working in `policyengine-canada`, prefer these PolicyEngine skills:

- `$policyengine-canada` for household-level Canadian tax and benefit calculations.
- `$policyengine-parameter-patterns` for parameter YAML files.
- `$policyengine-variable-patterns` for variable formulas and metadata.
- `$policyengine-testing-patterns` and `$policyengine-period-patterns` for YAML tests.
- `$policyengine-code-style`, `$policyengine-code-organization`, `$policyengine-aggregation`, and `$policyengine-vectorization` for implementation and review.
- `$policyengine-review-patterns` for reviewing Canada model changes.

PolicyEngine-Canada does not have representative population microdata. Do not do population-level microsimulation unless that changes.
