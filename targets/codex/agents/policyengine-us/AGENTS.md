# PolicyEngine-US Codex Routing

When working in `policyengine-us`, prefer these PolicyEngine skills:

- `$policyengine-us` for US domain knowledge: entities, programs, current-law values.
- `$policyengine-model-development` for variables, parameters, periods, vectorization, YAML tests, and in-model reforms (read its references for the topic at hand).
- `$review-program` for PR reviews, especially Codex `/review`.
- `$fix-pr` for applying review findings.
- `$encode-policy-v2` for implementing new state benefit programs.
- `$policyengine-standards` for formatting, CI, and PR standards.

For generic prompts like `/review`, "add a parameter", "write tests", or "fix a failing test", load the relevant skills above before editing.
