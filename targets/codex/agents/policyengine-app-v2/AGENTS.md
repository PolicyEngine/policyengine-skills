# PolicyEngine App Codex Routing

When working in `policyengine-app-v2`, prefer these PolicyEngine skills:

- `$policyengine-app` for app architecture, routing, and frontend conventions.
- `$policyengine-ui-kit-consumer` for `@policyengine/ui-kit`, globals CSS, PostCSS, and Tailwind utility issues.
- `$policyengine-tailwind-shadcn` for Tailwind v4 and shadcn patterns.
- `$policyengine-design` for PolicyEngine design tokens, colors, and visual identity.
- `$policyengine-recharts` for charts.
- `$policyengine-test-writing` for unit/component tests.
- `$seo-checklist` for SEO and crawlability work.

For generic prompts like `/review`, "fix styling", "write tests", or "add a component", load the relevant skills above before editing.
