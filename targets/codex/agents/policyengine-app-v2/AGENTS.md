# PolicyEngine App Codex Routing

When working in `policyengine-app-v2`, prefer these PolicyEngine skills:

- `$policyengine-app` for app architecture, routing, multizone config, and frontend conventions.
- `$policyengine-design` for design tokens, `@policyengine/ui-kit` consumption, Tailwind v4 theme setup, and chart styling.
- `$policyengine-api` for API integration (v1 endpoints, api-v2 alpha status).
- `$policyengine-standards` for formatters, CI, and PR conventions.

For generic prompts like `/review`, "fix styling", "write tests", or "add a component", load the relevant skills above before editing.
